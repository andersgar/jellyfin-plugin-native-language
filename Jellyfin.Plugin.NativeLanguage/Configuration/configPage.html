Native Language

Movies and series in the original languages you choose below get their original title, and the title is locked so metadata refreshes keep it. Everything else keeps the title from your library's metadata language.

Leave empty to use the same TMDb access as Jellyfin (the key from the TMDb plugin's settings, or Jellyfin's built-in key). Enter your own v3 API key or v4 read access token (themoviedb.org → Settings → API) to use that instead. Each title's original language is looked up once and cached.
Comma-separated ISO 639-1 codes, e.g. sv (Swedish) or no (Norwegian; nb and nn count as Norwegian too). With All except, try ja,ko,zh,th,ar,he,ru to keep titles in other scripts translated.
Recommended. Without the lock, the next metadata refresh can change the title back.
Only write what would change to the log, without changing anything.

Runs automatically when new items get metadata and after every library scan. To run it now: Dashboard → Scheduled Tasks → Apply native-language titles.
